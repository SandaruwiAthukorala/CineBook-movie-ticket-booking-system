# CineBook-movie-ticket-booking-system
CineBook is a dynamic web application designed for a cinema or movie theater to manage movies, showtimes, and customer ticket bookings. The system allows staff to add movie information, schedule screenings, and create bookings while checking seat availability.

## Technology Stack

- PHP 8 with Object-Oriented Programming
- MySQL
- HTML5, CSS3, JavaScript
- Bootstrap 5 and Bootstrap Icons
- XAMPP or WAMP

- ## Main Features

- User registration and login
- Movie catalogue with search and filters
- Movie details with available showtimes
- Seat selection with booked-seat blocking
- Payment simulation
- Booking history and cancellation
- Admin dashboard
- Admin CRUD for movies, theatres, and showtimes
- Admin booking management
- Responsive interface for desktop, tablet, and mobile
